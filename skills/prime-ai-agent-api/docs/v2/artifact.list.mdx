<Tip>
**Auth:**

- **API Key:** Full access.
- **Standard OAuth client:** Requires `create_task` or `manage_all_tasks`. With `create_task`, only artifacts from tasks created by the same client; see [Task visibility](<YOUR_LINK>).
- **Trusted client:** Full access.

**Guide:** Filter rules, artifact categories, URL lifetimes, pagination, and error codes are in the [Artifacts](<YOUR_LINK>) guide.
</Tip>
