<Tip>
**Auth:**

- **API Key:** Full access.
- **Standard OAuth client:** Requires `create_task` or `manage_all_tasks`. With `create_task`, only tasks created by the same client; see [Task visibility](<YOUR_LINK>).
- **Trusted client:** Full access.

**Handle status:** Read `status_update` events and respond as described in [Task Lifecycle](<YOUR_LINK>). Answer agent questions with [task.sendMessage](<YOUR_LINK>); confirm actions with [task.confirmAction](<YOUR_LINK>).

**Render output:** Resolve file paths and `prime-ai-agent-webdev://` links in assistant content as described in [Attachments](<YOUR_LINK>).
