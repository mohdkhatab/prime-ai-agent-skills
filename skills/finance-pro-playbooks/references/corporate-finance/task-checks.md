# Corporate-Finance Task Checks

Read only the selected task entry and its Playbook. These entries preserve the former task-level coverage and calculation topics as a review index, without executable checks or machine receipts. The Playbook and [metric dictionary](../metric-dictionary.md) explain applicable financial rules; explicit user conventions take precedence over defaults with accurate labeling.

Coverage topics are analytical checks, not mandatory visible headings or permission to expand the user's requested scope. Apply only the relevant topics, retain essential correctness checks, and disclose any requested narrowing that limits verification. Use genuine tools for arithmetic/file checks and an appropriate reviewer for complex semantics or release approval when required. Do not claim an independent review occurred unless it actually did.
