# Direct Finance Answers

Use for a narrow factual lookup or concept explanation without substantive modeling, investment recommendations, backtesting or a professional task deliverable. Answer in the user's requested language, structure, length and medium; a simple requested file does not automatically become a model task.

For a current figure, verify the requested entity/share class, date, unit and actual source. Inspect available authorized data capabilities, honor a requested source, and disclose unavailable or stale data. Cite the source actually used. Read [data-source-policy.md](data-source-policy.md) when using data. A concept explanation without current inputs needs no entity card or market-data retrieval.

Preserve explicit inputs, exclusions and corrections. Keep unknown values unknown and calculations reconstructable. If substantive calculations, strategy advice, sensitive inputs, publication or professional model work become material, use the corresponding domain and conditional references. Do not introduce full input forms, extra working files or companion reports solely to satisfy a framework. Privacy and transaction boundaries still apply.
